# Votação do mousepad YabaBuss

Página de votação para celular, com os 5 modelos: a pessoa coloca o nome, escolhe o modelo e vota.

- Link: https://contatogsfilmes-design.github.io/votacao-mousepad-yababuss/
- Os votos ficam no textdb.dev, um serviço gratuito sem conta. Ele não promete por quanto tempo guarda os dados, e qualquer pessoa com conhecimento técnico pode alterá-los.
- Apuração: `python apurar.py` mostra o placar e quem votou, e salva uma cópia em `apuracoes/`.
